SHELL SCRIPTING

======================================================================================================

A shell is a program that accepts commands from us and gives those commands to the operating system.

Types of shells in Linux

cat /etc/shells

1.sh
2.bash
3.zsh
4.ksh
5.fish
6.csh

Example:
Normally you execute commands one by one:
mkdir backup
cd backup
touch file.txt
echo "Hello" > file.txt

But suppose you have 20 commands.
Instead of typing them manually every time, put them inside a file.

Sample Script:

1.vim script.sh
#!/bin/bash
mkdir backup
cd backup
touch file.txt
echo "Hello" > file.txt

2.chmod +x script.sh
3.bash script.sh

DAY-14 NUMERIC OPERATORS

1.vim day14.sh
  #!/bin/bash
  
  a=20
  b=10

  if [ "$a" -eq "$b" ]
  then
      echo "Equal"

  elif [ "$a" -gt "$b" ]
  then
      echo "A is greater"

  else
      echo "B is greater"
  fi

2.chmod +x day14.sh
3.bash day14.sh

Output:
A is greater

Remember:
-eq → equal
-ne → not equal
-gt → greater than
-lt → less than
-ge → greater/equal
-le → less/equal
