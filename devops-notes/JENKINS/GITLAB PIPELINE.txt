===================================================

RUNNING MULTIPLE JOBS

#Build step
build-job:
    script:
        - echo "Building step"

test-job:
    script:
        - echo "Testing step"

deploy-job:
    script:
        - echo "Deployment step"

1.if we run the pipeline, pipeline runs in these format
  1.build-job
  2.deploy-job
  3.test-job

2.To run pipeline in the systematic order

stages:
    - build
    - test
    - deploy

build-job: 
    stage: build
    script:
        - echo "Building step"

test-job:
    stage: test
    script:
        - echo "Testing step"

deploy-job:
    stage: deploy
    script:
        - echo "Deployment step"

3.Again run the pipeline, pipeline runs in the order
  1.build-job
  2.test-job
  3.deploy-job

4.If suppose my build stage is failed then our test and deploy stage also failed, but if we want to manually run the test stage then we can simply run the test stage by clicking the resume icon

===================================================

RUNNING BASH SCRIPT

1.create a file in GitLab
basic.sh
  #!/bin/bash
  echo "These is from bash script"
  touch myfile.txt
  echo "Sample text" > myfile.txt
  echo "These is end of script..."

2.update .gitlab-ci.yml file

bash_execute: 
    script:
        - bash ./basic.sh

3.run & check the pipeline

4.But if you are creating files these files are not stored it in the project, u get the error like...
  {Cleaning up project directory and file based variables}

5.if we want to stored then we use the artifact

===================================================

GITLAB ARTIFACTS

1.update .gitlab-ci.yml

#To run bash script

bash_execute:
    script: 
        - mkdir myfolder
        - cp ./basic.sh myfolder/
        - cd myfolder
        - bash ./basic.sh
        - touch newfile
    artifacts: 
      paths: 
          - "./myfolder"
      when: on_success
      access: all
      expire_in: 30 days

2.Run the pipeline and check the logs

3.on the right side u get the artifact states
  1.keep 
  2.download
  3.browse

MANUAL DEPLOYMENT

1.update .gitlab-ci.yml 
2.and add the manual on deploy stage

stages:
    - build
    - test
    - deploy

build-job:
    stage: build
    script:
        - echo "Building step"

test-job:
    stage: test
    script:
        - echo "Testing step"

deploy-job:
    stage: deploy
    when: manual
    script:
        - echo "Deployment step"

2.Run the pipeline and check the pipeline

3.The build and test stage is success but deployment stage is not running, we can manually runs the stage by click on the resume button

PROJECT - STATIC WEB HOSTING

1.create a static-web-hosting repository
  1.index.html
  2.style.css

2.create a .gitlab-ci.yml

image: alpine:latest
pages
    script:
      - mkdir public
      - cp index.html style.css public
      
    artifacts: 
      paths: 
        - "public"
    only:
      - main

2.Run the pipeline & check the logs

3.click on artifacts
  1.browse
  2.click on public directory
  3.click on index.html file
  4.you get the website
