pipeline {
    agent {
        label 'worker'
    }

    tools {
        maven 'maven1'
    }

    environment {
        my_aws_credentials = credentials('aws-access')
    }

    stages {
        stage('Checkout') {
            steps {
                git 'https://github.com/mayurpandit25/studentapp-ui.git'
                echo 'Cloning is successful'
            }
        }

        stage('Build') {
            steps {
                sh 'mvn clean package'
                echo 'Build is successful'
            }
            post {
                success {
                    archiveArtifacts artifacts: '**/target/*.war', fingerprint: true
                }
            }
        }

        stage('Artifacts upload to S3') {
            steps {
                sh '''
                aws s3 cp target/studentapp-2.2-SNAPSHOT.war s3://amzon-mayur-s3-bucket-123/studentapp.war
                '''
                echo 'Artifacts uploaded to S3 successfully'
            }
        }

        stage('SonarQube Analysis') {
            steps {
                withSonarQubeEnv('sonar') {
                    sh 'mvn sonar:sonar'
                }
            }
        }

        stage('Quality Gate') {
            steps {
                timeout(time: 5, unit: 'MINUTES') {
                    script {
                        try {
                            def qg = waitForQualityGate()
                            echo "Quality Gate Status: ${qg.status}"
                            if (qg.status != 'OK') {
                                error "Quality Gate failed: ${qg.status}"
                            }

                        } catch (Exception e) {
                            echo "Quality Gate check failed: ${e.message}"
                            error "Quality Gate stage failed"
                        }
                    }
                }
            }
        }
    }
}

**SonarQube Quality Gate Block Explanation**

1.stage('Quality Gate') 
Purpose: Checks whether the code passed SonarQube Quality Gate.

2.timeout(time: 5, unit: 'MINUTES') {
Purpose: Waits a maximum of 5 minutes for SonarQube's response.

3.try (variable block like if/try/catch)
Purpose: Executes the code. If an error occurs, control goes to catch.

4.def qg = waitForQualityGate()
Purpose: Waits for SonarQube and stores the Quality Gate result in qg.

5.echo "Quality Gate Status: ${qg.status}"
Purpose: Prints the Quality Gate status in the Jenkins console.
Example: ok / Error / Failed

6.if (qg.status != 'OK') 
Purpose: Checks if the Quality Gate status is not OK.

7.error "Quality Gate failed: ${qg.status}"
Purpose: Stops the pipeline if the Quality Gate fails.

8.catch (Exception e) {
Purpose: Handles unexpected errors (server down, timeout, etc.).

9.echo "Quality Gate check failed: ${e.message}"
Purpose: Displays the actual error message.

10.error "Quality Gate stage failed"
Purpose: Marks the stage and pipeline as failed.
