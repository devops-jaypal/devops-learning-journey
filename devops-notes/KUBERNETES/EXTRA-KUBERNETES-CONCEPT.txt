Note 1 — Kubernetes NetworkPolicy

1.What NetworkPolicy is
  NetworkPolicy is a Kubernetes object used to control network traffic between Pods and/or between Pods and external networks.
  NetworkPolicy acts like a firewall for Kubernetes Pods.

It allows you to define:
- Which Pods can communicate with which Pods
- Which namespaces can communicate with which namespaces
- Which IP ranges can communicate with Pods
- Which ports are allowed
- Whether incoming traffic (Ingress) is allowed
- Whether outgoing traffic (Egress) is allowed

Suppose we have:
Frontend Pod -> Backend Pod -> Database Pod

We may want:
Frontend → Backend      ALLOW
Frontend → Database     DENY

Backend → Database      ALLOW
Backend → Frontend      DENY

Database → Backend      ALLOW
Database → Frontend     DENY

NetworkPolicy lets us implement this type of security.

-------------------------------------------------------------------------------

2.Why do we need NetworkPolicy

By default, Kubernetes networking is generally based on:
All Pods can communicate with all other Pods, subject to the networking implementation/CNI.

For Example:
Pod A
  ↕
Pod B
  ↕
Pod C
  ↕
Pod D

There is normally no application-level firewall saying:
"Pod A is allowed to talk to Pod B, but not Pod C."

This can become a security problem.

If an attacker compromises one Pod, unrestricted network access could allow the compromised Pod to communicate with services it should never access.
NetworkPolicy provides network segmentation.

4.Important Terminology

1.Ingress - incoming traffic coming to pod
  Frontend → Backend
           ↑
        Ingress


2.Egress  - Traffic going out
  Backend → Database
          ↑
        Egress

-------------------------------------------------------------------------------

5.NetworkPolicy structure

A basic NetworkPolicy looks like:

apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: example-policy
  namespace: default

spec:
  podSelector:
    matchLabels:
      app: backend

  policyTypes:
    - Ingress

  ingress:
    - from:
        - podSelector:
            matchLabels:
              app: frontend

-------------------------------------------------------------------------------

6.podSelector

podSelector:
  matchLabels:
    app: backend

Which Pods this NetworkPolicy applies to.

NetworkPolicy selects Pods using labels.
It does not normally select Pods by Pod name.
