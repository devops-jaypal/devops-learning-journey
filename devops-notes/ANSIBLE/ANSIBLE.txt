                                                                            ANSIBLE===>> configuration management tool

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------

1.ansible is a configuration management tools used for managing and installing the software on the existing servers.
2.it is based on python 3.9 or newer and work on the port no 22(ssh)

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------

1.creating a instance(master-node)
     1.name----------ansible-server
     2.machine-------centos
     3.type----------t2.micro
     4.key-----------id_rsa
     5.create a instance

2.create a instance(web-host)
     1.name---------web-host(node)
     2.machine -----centos
     3.type---------t2.micro
     4.key----------id_rsa 
     5.create a instance

3.access the ansible-server with (gitbash/mobaextreame/ubuntu/cmd)
     1.yum install epel-release
     2.yum install ansible -y
     3.hostnamectl set-hostname ansible-server

     4.get access of web-host on ansible server
          1.vim id_rsa
          2.chmod 700 id_rsa 
          3.ssh -i "id_rsa" centos@(private_ip of web-host) ----------------------------------private ip because they are in same network
       
     5.ls /etc/ansible/               --------------------------------------------------------files of ansible bydefault when u install ansible on server
         ansible.cfg-----> it's a main configuration file
         hosts-----------> it is a inventory that have the list of hosts-servers

     6.vim /etc/ansible/hosts  ---------------------------------------------------------------you can add host here
         delete all conf. and add {private ip of web-host}
         [demo]
         { private_ip of web-host }

     7.cat /etc/ansible/hosts
     8.cp /etc/ansible/hosts ./        -------------------------------------------------------copy hosts on the path where our keys should be stored

     9.ansible -i hosts all -u centos --private-key=./id_rsa/ -m shell -a hostname -----------command to configure on web-host
                
             { where -i = inventory purpose hosts server list
                     -u = user
                     -m = { define module means command of ansible }
                     -a = { argument }

**COLLECTSTATS
    in these file we can give facts from webserver.

1.create a collectfacts.yml file

---
- name: gathering facts from webserver 
  hosts: all 
  tasks: 
    - name: collect os name 
      debug:
        msg: "{{ansible_distribution}}"
    - name: collect ip addresses 
      debug:
        msg: "{{ansible_default_ipv4}}"
    - name: collect domain 
      debug: 
        msg: "{{ansible_domain}}"
...

2.git add .
  git commit -m "collect"
  git push origin main

3.git pull origin main

4.ansible-playbook collectfacts.yml

**REGISTRY**
    to store variables/values from one task and pass it to the other task

1.create a registry.yml file

---
- name: register values 
  hosts: all 
  tasks: 
    - name: get hostname
      shell: hostname 
      register: URL 
    - name: print hostname 
      debug:
        msg: "{{URL}}"
... 

2.git add .
  git commit -m "registry"
  git push origin main

3.git pull origin main

4.ansible-playbook registry.yml
